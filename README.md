# 🧩 Project Overview
This project is a vehicle license management system developed using C# and SQL Server.<br/>
The system focuses on security, controlled data access, and robust error handling.

## 🛠 Technologies Used
- C#
- SQL Server
- Windows Registry
- Database Views
- Windows Event Viewer

## 🔐 Security Features
- Secure login system
- User credentials stored as hashed values
- Sensitive data protected using Windows Registry
- Controlled data exposure through SQL Server Views

## 🗄 Database Design
SQL Server relational database
Views used to :
- Limit exposed columns
- Improve security
- Simplify data access for specific operations

## 🧪 Error Handling & Logging
- Application errors captured and logged using Windows Event Viewer
- Improved system reliability and easier debugging

## 🚀 Getting Started
Requirements
- Visual Studio
- SQL Server
- Windows OS

Run the Application
- Open the solution in Visual Studio
- Configure the database connection
- Run the application
